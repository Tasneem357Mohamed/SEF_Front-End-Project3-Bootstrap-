# 🏋️‍♀️ Carex – Modern Fitness & Wellness Website

**Train Smart. Live Strong. Built with Bootstrap 5 and Modern Web Technologies.**

Welcome to **Carex**, a responsive and dynamic **fitness and wellness website** developed as part of the **Front-End Development Course with SEF Academy**.  
This project focuses on mastering **Bootstrap 5** — leveraging its components, grid system, and built-in JavaScript utilities — alongside **HTML5** and **CSS3** to craft a professional and fully responsive user experience.

---

## 💪 About the Project

**Carex** was designed as a front-end practice project to explore **modern UI design** and **responsive layout building** using Bootstrap.  
The website aims to represent a **fitness and health brand**, offering sections for workouts, trainers, schedules, and membership plans — all styled with elegance and efficiency.

### ✨ Core Highlights
- **Bootstrap 5 Integration:** Used extensively for layout, navigation bars, modals, cards, and responsive grid systems.  
- **Built-in JS Components:** Implemented Bootstrap's JavaScript features such as **carousel**, **collapse**, and **modal popups**.  
- **Modern Aesthetic:** Balanced color palette and sleek design representing energy and wellness.  
- **Responsive Design:** Seamlessly adapts to mobile, tablet, and desktop views.

---

## 🧑‍💻 Tech Stack & Tools

- **HTML5** — Semantic structure and accessible content  
- **CSS3** — Custom styling and smooth transitions  
- **Bootstrap 5** — Responsive design, utility classes, and JS components  
- **Bootstrap JS Utilities** — Dynamic elements like modals, dropdowns, and carousels
